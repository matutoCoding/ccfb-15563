# 砖构工坊 BrickForge Studio

浏览器内的宠物照片 / 三维模型 → 颗粒积木摆件转换、结构校验与分步搭建图纸系统。技术栈为 **TypeScript + React + Vite + Three.js + WebGPU/WGSL**，数据默认保存在浏览器本地，工程可导出为 JSON 备份或跨设备导入。

## 快速开始

```powershell
npm install
npm run dev
```

打开终端输出的地址（当前固定为 <http://127.0.0.1:5157/>）。

生产构建：

```powershell
npm run build
npm run preview
```

运行结构与工程序列化测试：

```powershell
npm test
```

## 已实现的页面与能力

1. **订单列表**
   - 订单新建、编辑、删除、搜索和状态筛选。
   - 每个订单对应一个本地工程。
   - 工程 JSON 导出 / 导入；设置页支持整库备份。
   - 首次启动内置“坐着的猫”和“小房子”两个程序生成样例。

2. **模型导入**
   - OBJ：支持 `.obj + .mtl + 贴图` 多文件选择或拖拽。
   - glTF：支持 `.gltf + .bin + textures`，会重写相对资源为所选 Blob URL。
   - GLB：可直接导入二进制。
   - UV 贴图 / 材质颜色会烘焙到三角顶点色，供体素配色使用。

3. **体素化**
   - 最长边分辨率支持 48 / 64 / 80 / 96 / 128。
   - 优先使用 WebGPU WGSL compute shader：每个三角形一个线程，在其 AABB 内做最近三角形检测并写入原子计数颜色。
   - 浏览器无 WebGPU 或 shader 初始化失败时，自动使用等价 CPU 保守体素化。
   - 多源邻域扩张形成厚壳；默认壳厚 2，可调 1–3。
   - 薄件修复采用只扩张不侵蚀策略，避免细尾、耳尖、屋檐等位置断开。
   - 内部掏空省料，同时保留外表面和内腔表面壳层。

4. **配色**
   - 27 种常用颗粒色 + 临时支撑橙。
   - 贴图颜色经 Lab/加权 RGB 匹配到现有色卡。
   - 可锁定颜色区域；重新量化时保留锁定体素。
   - 可切换色卡库存；未锁定的缺货颜色自动替换为最近在库色。

5. **合砖与结构**
   - 砖型包含 1×1、1×2、1×3、1×4、2×2、2×3、2×4，并支持朝向旋转。
   - 同色连续体素才会合并，避免一块砖出现多个颜色。
   - 贪心枚举合法矩形，按面积、下咬合凸点数、跨过下层砖缝、同尺寸对齐惩罚和层间方向偏好评分。
   - 相邻层自动交错跑缝，避免整列对齐。
   - 自动生成最短 1×1 支撑柱，直到地面或已有砖。
   - 结构页标记悬空和“仅一个凸点连接”的位置；可一键补强第二咬合点。
   - 硬验收：开启自动支撑后，除底层与底板接触外，每块 `y > 0` 的砖至少与下层一块砖有一个凸点咬合，`floatingCount = 0`。

6. **搭建图纸**
   - 每层是一个步骤，滑块 / 上一步 / 下一步 / 自动播放。
   - 当前层只实体显示新砖；旧层可切换为半透明参考。
   - 三维视图可旋转、缩放、平移，使用实例化砖体和凸点。
   - 每步零件清单、本层 CSV、完整 BOM CSV。
   - 导出中文分步 PDF：每页含三维步骤图、本层新增数量和零件表（中文直接绘制到 Canvas，避免 jsPDF 字体缺字）。
   - 导出 2000px 成品效果图 PNG。

7. **设置**
   - WebGPU 适配器状态。
   - 颗粒齿距、砖高、凸点尺寸说明。
   - 96 分辨率性能自测。
   - 全部订单 / 工程 JSON 备份、导入和清空本地缓存。

## 性能说明

合砖器是线性扫描加固定砖型候选；103,214 个占用体素的球形壳基准中，合砖与结构规划约 **0.2 秒**（开发机 Node/Vitest），显著低于 10 秒目标。完整模型的主要变量是源三角面数量和浏览器 WebGPU/CPU 性能；WebGPU 路径把三角形 AABB 体素测试放到 GPU，CPU 路径用于兼容和测试。

## 结构口径与已知边界

- 规划器以“一个网格单元 = 一个凸点间距”，一层对应一皮标准砖。
- 当前版本将每块砖视为一皮高，暂未混合薄板 / 高砖。
- 1×1 砖物理上只有一个下凸点，因此即使方案合格，也可能保留为单凸点警告；结构页不会隐藏这一风险。
- 自动支撑默认只消除悬空；“补强单凸点连接”会增加支撑砖，可在体素页或图纸结构页开启。
- 浏览器 WebGPU 可用性取决于浏览器版本、系统和硬件加速；不可用时功能仍可通过 CPU 回退完成。
