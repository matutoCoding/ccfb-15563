# BrickForge 积木定制工作台

浏览器端的颗粒积木模型转换与搭建图纸系统:客户照片重建的 OBJ / glTF 模型 → 体素化 → 掏空省料 → 色卡配色 → 真实砖型合砖 → 结构稳定性分析与自动支撑 → 分步搭建图纸与 PDF/CSV 导出。

技术栈:TypeScript + React + Zustand + WebGPU(计算着色器体素化、实例化塑料渲染),无 WebGPU 时自动回退到数学实现完全一致的 CPU 路径。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm test           # 22 个测试:结构不变量、配色、解析器、工程往返、性能基线
npm run build      # 类型检查 + 生产构建
```

Chrome / Edge 113+ 可获得完整 WebGPU 体验;其他浏览器核心转换功能不受影响。

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 订单列表 | 订单增删改、状态流转、工程 `.bfproj` 导出/导入(IndexedDB 持久化) |
| 模型导入 | OBJ(+MTL/贴图)、glTF/GLB(+bin/贴图)解析;无模型时一键生成坐姿猫、小房子 |
| 体素化 | 分辨率/壳厚/颗粒尺寸/砖型可调,GPU 与 CPU 双路径,实时显示各阶段耗时 |
| 配色 | 21 色颗粒色卡,redmean 感知量化,颜色锁定,缺货自动换最近色 |
| 搭建图纸 | 按层分步、只高亮新砖、半透明未搭建、逐步零件清单,导出 PDF/CSV/效果图 |
| 设置 | 工艺默认值、砖型开关、库存状态、运行环境与算法说明 |

## 结构红线如何保证

1. **每块非落地砖至少咬合一块下层砖**:合砖候选打分中零咬合直接压到最低,硬悬空位置先补 1x1 支撑柱再放砖,并有独立的 `analyzeStability` 复核(测试硬性断言)。
2. **无悬空体素**:合砖后逐体素检查正下方支撑;`addSupports` 对悬挑自动补柱到地面/实心层,且支撑柱与上下砖建立双向咬合,幂等可重复执行。
3. **层间交错**:候选打分奖励跨多块下层砖、惩罚与下层同轮廓对齐,奇偶层扫描方向交替。
4. **薄壁不断开**:掏空基于 26 邻接切比雪夫距离场,所有表面体素距离恒为 1,壳厚参数只删内部体素;测试验证掏空后外壳 6-连通为一个整体。

## 性能

10 万体素级模型的「体素化 + 掏空 + 配色 + 合砖」实测约 **0.3–0.4 秒**(`tests/perf.test.ts`,预算 10 秒)。耗时在体素化页分阶段展示。

## 目录

```
src/core/      纯 TS 算法(无 DOM 依赖,全部可单测)
  voxelize.ts    SAT 三角形-盒子重叠、CPU 体素化、泛洪填腔、距离场掏空
  merger.ts      分层贪心合砖、交错咬合打分、支撑柱
  stability.ts   稳定性复核与自动加固
  palette.ts     色卡、redmean 量化、缺货换色
  objParser.ts / gltfParser.ts / procedural.ts
src/gpu/       WGSL 计算着色器体素化 + 实例化砖渲染器(凸点、塑料光照)
src/pages/     六个业务页面
src/state/     Zustand store + IndexedDB
tests/         22 个测试,含结构不变量与性能基线
```
